Przywracanie / Wlaczenie menu GRUB (Ubuntu i inne)

Kiedy to sie przydaje?
Gdy po wlaczeniu komputera od razu uruchamia Ci sie Ubuntu (lub Windows), nie dajac mozliwosci wyboru systemu. Ponizsza instrukcja zmusi komputer, by przy starcie zawsze pokazywal menu wyboru systemow operacyjnych.

Krok 1: Otwarcie pliku konfiguracyjnego

Otworz terminal w systemie Linux i wpisz ponizsza komende, aby edytowac ustawienia GRUB jako administrator:

sudo nano /etc/default/grub

Krok 2: Edycja ustawien

Odszukaj w pliku ponizsze linijki i zmien ich wartosci. Jesli ktorejs z nich w ogole nie ma w pliku - dopisz ja na samym dole:

GRUB_TIMEOUT=10 # Czas (w sekundach), przez jaki menu bedzie czekac na Twoj wybor GRUB_TIMEOUT_STYLE=menu # Wymusza wyswietlanie tradycyjnego menu wyboru systemu GRUB_HIDDEN_TIMEOUT=0 # Wylacza ukrywanie menu na start komputera

Jak zapisac zmiany w edytorze nano?
Gdy skonczysz edycje, wcisnij kombinacje klawiszy Ctrl + O, a nastepnie wcisnij Enter (aby zapisac plik).
Nastepnie wcisnij Ctrl + X, aby bezpiecznie wyjsc z edytora z powrotem do terminala.

Krok 3: Zatwierdzenie zmian w systemie

Samo zapisanie pliku nie wystarczy. Musisz poinformowac system operacyjny o zmianach. Wpisz w terminalu kluczowa komende:

sudo update-grub

System przetworzy plik i zaktualizuje pliki startowe komputera.

Krok 4: Restart

Teraz uruchom komputer ponownie wpisujac sudo reboot lub klikajac restart w systemie. Podczas uruchamiania powinno pojawic sie upragnione menu wyboru systemow.
