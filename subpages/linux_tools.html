Linux - Przydatne Narzędzia

Poniżej znajdziesz listę podstawowych programów, które warto zainstalować na swoim serwerze Linux. Obok każdego programu znajdziesz komendę instalacyjną oraz instrukcję, jak go włączyć.

1. Midnight Commander (MC) – Graficzny menedżer plików

Co to robi? Taki "Eksplorator plików" lub "Total Commander", ale w trybie tekstowym. Pozwala wygodnie przeglądać foldery, kopiować i usuwać pliki za pomocą strzałek, zamiast wpisywać ręcznie długie komendy.
Jak zainstalować: sudo apt install mc
Jak uruchomić: Wpisz w terminalu mc i wciśnij Enter. Aby wyjść, wciśnij klawisz F10.

2. Lynx – Przeglądarka internetowa w terminalu

Co to robi? Pozwala przeglądać strony internetowe (np. Google czy Wikipedię) bezpośrednio w czarnym oknie terminala. Nie wyświetla obrazków, tylko sam tekst – idealne, gdy serwer nie ma interfejsu graficznego.
Jak zainstalować: sudo apt install lynx
Jak uruchomić: Wpisz lynx google.pl (albo dowolny inny adres), aby wejść na stronę. Aby wyjść, wciśnij klawisz Q, a potem Y.

3. Dmidecode – Sprawdzanie części komputera

Co to robi? Wyciąga z płyty głównej informacje o podzespołach. Dzięki temu dowiesz się np. ile masz pamięci RAM, jaki masz procesor i model płyty, bez rozkręcania obudowy komputera.
Jak zainstalować: sudo apt install dmidecode
Jak uruchomić: Ten program wymaga uprawnień administratora. Wpisz sudo dmidecode. Na ekranie pojawi się ogromna lista – możesz przewijać ją myszką lub strzałkami.

4. Net-tools – Narzędzia sieciowe

Co to robi? Zestaw klasycznych narzędzi do sprawdzania sieci. Zawiera m.in. kultową komendę ifconfig, dzięki której szybko sprawdzisz swój adres IP oraz dowiesz się, czy masz połączenie z internetem.
Jak zainstalować: sudo apt install net-tools
Jak uruchomić: To nie jest jeden program, a paczka narzędzi. Najważniejsze z nich uruchamiasz wpisując ifconfig. Twój adres IP znajdziesz w sekcji "inet".

5. OpenSSH Server – Zdalne sterowanie komputerem

Co to robi? Pozwala "zalogować się" na Twój serwer Linux z innego komputera w domu lub na świecie. Po instalacji możesz schować serwer do szafy i zarządzać nim siedząc wygodnie na kanapie z laptopem.
Jak zainstalować: sudo apt install openssh-server
Jak uruchomić: Tego programu nie uruchamiasz na serwerze – on działa sam w tle jako "odbiornik". Aby się z nim połączyć z innego komputera (np. z Windowsa), otwierasz tam program *PuTTY* lub zwykły terminal i wpisujesz: ssh nazwa_użytkownika@adres_ip_serwera.

6. VIM – Zaawansowany edytor tekstu

Co to robi? Notatnik dla profesjonalistów uruchamiany w terminalu. Służy do edycji plików konfiguracyjnych i pisania skryptów. Uwaga: ma specyficzne sterowanie, przez co na początku trudno z niego wyjść!
Jak zainstalować: sudo apt install vim
Jak uruchomić: Wpisz vim nazwa_pliku.txt, aby utworzyć lub edytować plik. Ważna podpowiedź dla początkujących: Żeby zacząć pisać, wciśnij klawisz I (tryb wprowadzania). Żeby zapisać i wyjść, wciśnij klawisz Esc, a potem wpisz :wq i wciśnij Enter.
