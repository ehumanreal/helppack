Linux - Przydatne Narzedzia

Ponizej znajdziesz liste podstawowych programow, ktore warto zainstalowac na swoim serwerze Linux. Obok kazdego programu znajdziesz komende instalacyjna oraz instrukcje, jak go wlaczyc.

1. Midnight Commander (MC) - Graficzny menedzer plikow

Co to robi? Taki "Eksplorator plikow" lub "Total Commander", ale w trybie tekstowym. Pozwala wygodnie przegladac foldery, kopiowac i usuwac pliki za pomoca strzalek, zamiast wpisywac recznie dlugie komendy.
Jak zainstalowac: sudo apt install mc
Jak uruchomic: Wpisz w terminalu mc i wcisnij Enter. Aby wyjsc, wcisnij klawisz F10.

2. Lynx - Przegladarka internetowa w terminalu

Co to robi? Pozwala przegladac strony internetowe (np. Google czy Wikipedie) bezposrednio w czarnym oknie terminala. Nie wyswietla obrazkow, tylko sam tekst - idealne, gdy serwer nie ma interfejsu graficznego.
Jak zainstalowac: sudo apt install lynx
Jak uruchomic: Wpisz lynx google.pl (albo dowolny inny adres), aby wejsc na strone. Aby wyjsc, wcisnij klawisz Q, a potem Y.

3. Dmidecode - Sprawdzanie czesci komputera

Co to robi? Wyciaga z plyty glownej informacje o podzespolach dzieki temu dowiesz sie np. ile masz pamieci RAM, jaki masz procesor i model plyty, bez rozkrecania obudowy komputera.
Jak zainstalowac: sudo apt install dmidecode
Jak uruchomic: Ten program wymaga uprawnien administratora. Wpisz sudo dmidecode. Na ekranie pojawi sie ogromna lista - mozesz przewijac ja myszka lub strzalkami.

4. Net-tools - Narzedzia sieciowe

Co to robi? Zestaw klasycznych narzedzi do sprawdzania sieci. Zawiera m.in. kultowa komende ifconfig, dzieki ktorej szybko sprawdzisz swoj adres IP i dowiesz sie, czy masz polaczenie z internetem.
Jak zainstalowac: sudo apt install net-tools
Jak uruchomic: To nie jest jeden program, a paczka narzedzi. Najwazniejsze z nich uruchamiasz wpisujac ifconfig. Twoj adres IP znajdziesz w sekcji "inet".

5. OpenSSH Server - Zdalne sterowanie komputerem

Co to robi? Pozwala "zalogowac sie" na Twoj serwer Linux z innego komputera w domu lub na swiecie. Po instalacji mozesz schowac serwer do szafy i zarzadzac nim siedzac wygodnie na kanapie z laptopem.
Jak zainstalowac: sudo apt install openssh-server
Jak uruchomic: Tego programu nie uruchamiasz na serwerze - on dziala sam w tle jako "odbiornik". Aby sie z nim polaczyc z innego komputera (np. z Windowsa), otwierasz tam program PuTTY lub zwykle terminal i wpisujesz: ssh nazwa_uzytkownika@adres_ip_serwera.

6. VIM - Zaawansowany edytor tekstu

Co to robi? Notatnik dla profesjonalistow uruchamiany w terminalu sluzy do edycji plikow konfiguracyjnych i pisania skryptow. Uwaga: ma specyficzne sterowanie, przez co na poczatku trudno z niego wyjsc!
Jak zainstalowac: sudo apt install vim
Jak uruchomic: Wpisz vim nazwa_pliku.txt, aby utworzyc lub edytowac plik. Wazna podpowiedz dla poczatkujacych: Żeby zaczac pisac, wcisnij klawisz I (tryb wprowadzania). Żeby zapisac i wyjsc, wcisnij klawisz Esc, a potem wpisz :wq i wcisnij Enter.
