Konfiguracja sieci (Netplan)

Srodowisko testowe: Ponizsze konfiguracje byly testowane i dzialaja na Ubuntu Server 24.04.1 LTS.
BARDZO WAZNA ZASADA (Format YAML):
Pliki Netplana NIE NAWIDZA klawisza TAB! Do robienia wciec w tekscie uzywaj WYLACZNIE spacji. Jesli wkleisz tam tabulator, system wyrzuci blad i siec nie zadziala.
Uwaga na nazwy kart sieciowych:
Nazwy kart (np. enp2s5, enp1s0, enp0s25) w Twoim komputerze moga byc zupelnie inne! Zanim bezmyslnie skopiujesz kod, sprawdz jak nazywaja sie Twoje karty wpisujac w terminalu komende: ip a.

W zaleznosci od tego, jak zainstalowales system, Twoj plik konfiguracyjny moze znajdowac sie w jednej z dwoch lokalizacji ponizej. Edytujesz go komenda: sudo nano /sciezka/do/pliku.yaml

Wariant 1: Plik cloud-init

Sciezka do pliku: /etc/netplan/50-cloud-init.yaml

Ten wzorzec konfiguruje dwie karty: jedna wylacza (brak automatycznego IP), a drugiej przypisuje staly, reczny adres IP.

network:
  ethernets:
    enp2s5:                  # Nazwa Twojej pierwszej karty
      dhcp4: false           # false = WYLACZONE automatyczne pobieranie IP (czysta karta)
    enp1s0:                  # Nazwa Twojej drugiej karty
      addresses:
        - 172.20.0.3/24      # Staly adres IP serwera (koncowka /24 to tzw. maska sieci)
      nameservers:
        addresses:
          - 172.20.0.1       # Adres DNS (serwer, ktory tlumaczy nazwy stron na IP, np. router)
      routes:
        - to: 0.0.0.0/0      # Regula: "caly ruch w swiat..."
          via: 172.20.0.1    # "...wysylaj przez te brame (router)"
  version: 2

Wariant 2: Plik instalatora

Sciezka do pliku: /etc/netplan/00-installer-config.yaml

Ten wzorzec konfiguruje az trzy karty sieciowe: dwie na sztywno (stale IP), a trzecia ma automatycznie pobierac adres z routera (DHCP).

network:
  ethernets:
    enp0s25:                 # Pierwsza karta
      dhcp4: false           # Wylaczone automatyczne IP
    enp1s0:                  # Druga karta
      addresses:
        - 10.10.10.2/24      # Staly, reczny adres IP serwera
      nameservers:
        addresses:
          - 10.10.10.1       # Adres serwera DNS
        search: []           # Pusta lista wyszukiwania domen (standard)
    enp2s5:                  # Trzecia karta
      dhcp4: true            # true = WLACZONE automatyczne pobieranie IP z routera (DHCP)
  version: 2

Jak zatwierdzic zmiany? (Zeby siec zaczela dzialac)

Samo zapisanie pliku tekstowego nic nie zmieni. Musisz zmusic system, zeby wczytal nowa konfiguracje. Wpisz w terminalu:

sudo netplan apply

Jesli nie pojawil sie zadny komunikat - gratulacje, siec dziala! Jesli wyskoczyl blad, sprawdz, czy nie uzyles tabulatora albo czy nie brakuje gdzies spacji.
